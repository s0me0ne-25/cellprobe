## 1. Принцип: позитивная терминология

Используем терминологический подход в духе ФСПО: негативной терминологии вроде «обход», «circumvention» и т. д. избегаем; используем позитивную — «противодействие цензуре», «борьба с блокировками», «разблокировка» и т. д. Пользователь Cellprobe и другого противоцензурного софта — это не маргинал, который крадётся в дырку в заборе, а человек, защищающий свои человеческие права.

| Избегаем | Используем (RU) | Use (EN) |
|---|---|---|
| обход блокировок, обходить блокировки | разблокировка, противодействие блокировкам, борьба с блокировками, восстановить доступ | unblocking, resisting blocking, restoring access |
| средство обхода, способ обхода | средство разблокировки, противоцензурный инструмент | unblocking tool, anti-censorship tool |
| circumvention, bypass (о цензуре), evasion | — | anti-censorship, unblocking |
| «серый», «нелегальный», «в обход закона» о средствах разблокировки | не используем | not used |

**Не подпадают под принцип** — и потому допустимы:
- технические термины, описывающие механику протоколов, а не пользователя: «сайт-прикрытие» (`dest` у Reality), «маскировка трафика»;
- общеязыковые слова не о цензуре: «обходится без разрешения», «не обойтись», «bypass the cache» в комментарии к коду.

## 2. Термины интерфейса

Один термин — одно написание. Новые термины дописываются сюда до того, как появляются в интерфейсе.

| Понятие | RU | EN | Не используем |
|---|---|---|---|
| Приложение пользователя для VPN/прокси | VPN-клиент | VPN client | проксификатор, proxy app |
| Протокол | VLESS/Reality | VLESS/Reality | VLESS-Reality, VLESS+Reality, Vless |
| Запись пользователя о своём сервере | VLESS-вход | VLESS inbound | инбаунд |
| Сайт оператора для оплаты | ЛК провайдера (полностью — личный кабинет провайдера) | provider account page | |
| Режим сети, где доступен только разрешённый список | режим белого списка | whitelist mode | БС |
| Оборудование фильтрации | ТСПУ | regulatory firewalls | censor's equipment |
| Удостоверяющий центр Минцифры (корневой и промежуточные сертификаты, которые нужно установить) | УЦ Минцифры | Russian state CA | «сертификаты Минцифры» в этом значении |
| Сертификаты сайтов, выпущенные УЦ Минцифры | сертификаты Минцифры | Russian state certificates | |
| Отпечаток TLS-клиента (`fp`) | отпечаток | fingerprint | |
| Подстрока для проверки содержимого | маркер | marker | |
| Встроенный набор записей списка | пресет | preset | |
| Ручная проверка | «Проверить сейчас», «Проверка ресурсов» | "Check now", "Resource check" | |

### Названия списков

| № | RU | EN |
|---|---|---|
| 1 | Всегда доступные | Always reachable |
| 2 | Блокируются в режиме белых списков | Blocked in whitelist mode |
| 3 | VLESS-входы | VLESS inbounds |
| 4 | Заведомо заблокированные | Known blocked |
